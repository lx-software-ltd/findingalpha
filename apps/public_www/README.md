# Finding Alpha public website

Single page: dark background, brand logo centred, nothing else.

## Local

```bash
npm install
npm run dev
```

Dev server: `http://localhost:5173/`.

## Checks

```bash
npm test
npm run lint
npm run build
npm run preview
```

## Deploy

Hosting (S3 + CloudFront) is not in this app yet. A follow-up red-zone
change can copy the `lx-software` public website stack and deploy
workflow.
